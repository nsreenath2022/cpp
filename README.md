# Thread-Safe Singleton Implementation in C++

## Overview

This project demonstrates how to implement a **Singleton pattern** in C++ that is **thread-safe**. It shows different ways to ensure that only one instance of a class exists even when multiple threads try to create the instance at the same time.

### Features:
- **3 variations of Singleton** patterns with examples.
- **Thread-safety** using `std::mutex` to protect the instance.
- Simple and easy-to-understand code.
- Follows **C++ best practices**.
